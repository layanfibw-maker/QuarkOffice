# QuarkOffice roadmap

## Phase 1 — Foundation
- define the product brand and architecture
- set up the repo, tooling, and developer workflow
- align the app shell with a modern office suite identity

## Phase 2 — Editor core
- document editor for .docx and Markdown
- spreadsheet engine for .xlsx and formulas
- presentation engine for .pptx and slide layouts

## Phase 3 — AI capabilities
- smart writing assistance
- spreadsheet analysis and suggestions
- slide generation from content prompts
- local AI orchestration

## Phase 4 — Collaboration
- shared editing sessions
- comments and review workflow
- file sync and permissions

## Phase 5 — Self-hosting and production readiness
- packaged desktop app
- deployment docs
- CI/CD and release pipelines
