# QuarkOffice

QuarkOffice is a modern open-source AI office suite built for local-first productivity, real-time collaboration, and strong compatibility with Microsoft Office documents.

This repository is the starting point for a QuarkOffice brand based on the GenOffice design and feature direction, rebranded and adapted for a cleaner, more productized open-source ecosystem.

## Goals

- Create a full office suite for documents, spreadsheets, and presentations
- Stay compatible with .docx, .xlsx, .pptx, PDF, Markdown, and HTML
- Offer local AI workflows without forcing cloud dependencies
- Provide a clean and self-hostable workspace for teams and individuals
- Keep the project fully open source and privacy-aware

## Product vision

QuarkOffice aims to combine:

- document editing
- spreadsheet work
- slide presentations
- PDF handling
- AI-assisted editing
- collaborative workflows
- cross-platform desktop and web support

## Current status

This repo is in its initial bootstrap phase. The foundation is being prepared for the next stage:

- project branding
- architecture setup
- app shell
- office document engine integration
- AI document workflows
- collaboration layer
